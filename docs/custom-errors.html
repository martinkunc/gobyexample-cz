Je možné definovat vlastní typy chyb, když k nim implementujeme metodu Error(). Zde je varianta příkladu nahoře, která používá vlastní typ pro konkrétní určení chyby argumentu.

 
package main

import (
    "errors"
    "fmt"
)

Vlastní typ chyby má obvykle příponu “Error”.

 
type argError struct {
    arg     int
    message string
}

Přidáním této metody Error bude argError implementovat interface error.

 
func (e *argError) Error() string {
    return fmt.Sprintf("%d - %s", e.arg, e.message)
}

errors.AsType je pokročilejší verze errors.Is. Kontroluje, zda daná chyba (nebo jakákoli chyba v jejím řetězci) odpovídá konkrétnímu typu chyby, převede ji na hodnotu tohoto typu a vrátí také true. Pokud shoda není, druhá návratová hodnota je false.
