Go podle Příkladů: Chyby (errors)

V Go je přirozené komunikovat chyby pomocí explicitních, oddělených návratových hodnot. To je v kontrastu k výjimkám používaným v jazycích jako Java, Python a Ruby a přetíženým samostatným hodnotám výsledku/chyby někdy používaným v C. Go přístup usnadňuje zjištění, zda funkce vrací chyby, a jejich ošetření stejnými jazykovými prostředky jako pro úkoly, které se netýkají chyb.

errors.New vytváří základní hodnotu error se zadanou chybovou hláškou.

Hodnota nil na pozici chyby naznačuje že nedošlo k chybě.

errors.Is kontroluje, zda daná chyba (nebo jakákoli chyba v jejím řetězci) odpovídá konkrétní hodnotě chyby. To je užitečné hlavně u obalených nebo vnořených chyb, kde tak můžete v řetězci chyb rozpoznat konkrétní typy chyb nebo sentinelové chyby.

 
            if errors.Is(err, ErrDoselCaj) {
                fmt.Println("Měli bychom koupit nový čaj!")
            } else if errors.Is(err, ErrProud) {
                fmt.Println("Teď je tma.")
            } else {
                fmt.Printf("neznámá chyba: %s\n", err)
            }
            continue
        }

        fmt.Println("Čaj je hotový!")
