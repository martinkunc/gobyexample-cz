Třídicí funkce jsou generické a fungují pro jakýkoli uspořádaný zabudovaný typ. Seznam uspořádaných typů najdete v cmp.Ordered.

 
    strs := []string{"c", "a", "b"}
    slices.Sort(strs)
    fmt.Println("Řetězce:", strs)

Příklad třídění intů.

 
    ints := []int{7, 2, 4}
    slices.Sort(ints)
    fmt.Println("Inty:   ", ints)

Balíček slices můžeme také použít pro kontrolu, jestli je výřez už v setříděném pořadí.

 
    s := slices.IsSorted(ints)
    fmt.Println("Setříděný: ", s)
}
